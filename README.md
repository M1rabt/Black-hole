# Black Hole Simulator

A dependency-free, interactive black hole illustration with an animated accretion disk, stars, and a beginner-friendly guide to black hole concepts.

Open `index.html` or `black-hole.html` in a modern browser. Adjust the visual mass and disk-rotation settings, pause or reset the animation, or use fullscreen when supported. Keyboard shortcuts are **Space** to pause or resume, **R** to reset, and **F** for fullscreen. The controls change visual settings only; this is not a physics simulation, and its readouts are not measurements or predictions.

Select **Explore in 3D** to open the real-time WebGL Explorer. Drag to orbit, use the mouse wheel or a two-finger pinch to zoom, or use the on-screen zoom and reset controls. Arrow keys orbit, **+ / −** zoom, **R** resets the view, and **Esc** returns to the simulator. Fullscreen is available when supported by the browser. The Explorer uses a lightweight built-in shader renderer and needs no additional libraries; if WebGL is unavailable, the original simulator remains usable.
